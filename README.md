# Huge To Scale

English YouTube Shorts without voice: real huge objects placed in familiar places at their true size.
3D in Blender (Cycles), CC0 music, sizes checked against two sources. Fully automatic on GitHub Actions.

Status: test stage. Automation is **off** until the owner's go-ahead.

- `branding3d/` — channel art (banner, avatar) rendered in Blender; sources and licences in `branding3d/sources.json`
- `shorts/` — Short scenes and test frames
- `scripts/check_repo.py` + `.github/workflows/guard.yml` — no secrets, no personal e-mail, no heavy files in this public repo

Map data © OpenStreetMap contributors (ODbL). Borders: Natural Earth (public domain).
3D models of NASA spacecraft: NASA 3D Resources (no endorsement by NASA implied).
